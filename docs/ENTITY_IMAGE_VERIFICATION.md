# 产品形象与实体欢迎验收

2026-09-12，本机静态服务 127.0.0.1:8765；使用 Chrome 独立测试上下文，不改用户实际浏览器数据。

## 已验证

- 先运行 `tests/entity-chat.browser.js`，旧实现因欢迎消息内没有产品图而失败；实现后测试通过。
- Chat 回归覆盖：图片实际解码、产品名称作为说话者、自定义/默认第一人称欢迎、卡片留在 Chat、新对话保留图片、无图回退。
- 管理端上传测试 PNG 后压缩保存为 WebP，刷新后预览恢复；C 端显示头部头像及欢迎消息图片、自定义欢迎语。
- 损坏 PNG、超过 2MB、SVG 文件均拒绝，不覆盖原图。
- 移除图片并保存，刷新 C 端后图像消失、欢迎语保持。
- 上传尚在解码时立即创建另一产品，异步结果没有写入新产品。
- 375×812 手机视口：页面宽度与滚动宽度均为 375，无横向溢出；输入框可见，卡片全部位于聊天消息中。
- C 端浏览器控制台无 error/warn；admin.js、public.js、chat-ui-kit.js 语法检查通过。

## 使用与边界

管理端「产品身份」上传真实产品图；「Agent 设定」填写实体欢迎语，保存后刷新 C 端。欢迎标题自动使用产品名称，欢迎语可只写接下来的第一人称内容。留空使用默认问候。

测试图片只是独立测试上下文内的标记方图，并非产品素材。模型仍为本地模拟，语气和角色配置尚不驱动真实模型；图片仍存浏览器 localStorage，保存空间不足会提示失败，不部署服务器。若旧标签页仍显示旧样式，强制刷新。
